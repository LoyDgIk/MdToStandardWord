# 范围

本文件规定了智能座舱的分级方法、技术要求和综合评价指标。

本文件适用于乘用车智能座舱的设计、开发与评价。

# 术语和定义

下列术语和定义适用于本文件。

## 智能座舱  intelligent cockpit

以驾乘人员为中心，融合多模态交互、场景感知与服务的车内空间系统。

## 多模态交互  multimodal interaction

综合运用语音、触控、视觉等多种方式进行人机信息交换的交互形式。

# 分级方法

## 分级原则

智能座舱按交互能力、感知能力和服务能力分为 L0 至 L4 共 5 个等级。

分级应遵循下列原则：

- 以驾乘人员的实际体验为核心；
- 兼顾安全性与可用性；
- 可量化、可验证。

## 等级划分

各等级的能力要求如下：

1. L0：仅提供基础信息显示；
2. L1：支持单一模态交互；
3. L2：支持多模态交互与基础场景感知。

{表：#tbl:levels} 智能座舱分级能力对照

| 等级 | 交互能力 | 感知能力 | 服务能力 |
| --- | --- | --- | --- |
| L0 | 基础 | 无 | 无 |
| L1 | 单模态 | 弱 | 基础 |
| L2 | 多模态 | 中 | 进阶 |

注：上表中的能力等级仅用于示意，具体指标见第6章。

# 综合评价

## 评价指标

综合评价包括交互效率、场景适应性和用户满意度三个维度。

示例：交互效率可用任务完成时间与操作步数综合衡量。

## 评价方法

应采用 **客观测试** 与 *主观评分* 相结合的方法进行评价。

# 附录 规范性 分级判定流程

## 判定步骤

按下列步骤进行分级判定：

- 确定座舱具备的交互模态数量；
- 评估场景感知与服务能力；
- 综合得出等级。
