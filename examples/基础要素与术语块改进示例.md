# 范围

本文件给出了标准生成器基础要素和术语块输入格式的示例。

本文件适用于验证 Markdown 转换为标准文本 Word 时的封面字段、正文首页提示、标准章导语、术语条目、注和来源生成效果。

# 规范性引用文件

# 术语和定义

{术语：基础要素 | basic element}

标准文件中用于表达封面信息、正文首页提示、标准章导语和其他固定结构的信息单元。

注：在本示例中，基础要素由 YAML front matter 和标准章标题共同触发生成。

[来源：GB/T 1.1—2020，3.1，有修改]

{术语：术语块 | term block}

以显式 Markdown 标记声明术语、英文对应词、定义、注和来源的结构化输入片段。

注：术语块推荐写作 `{术语：中文术语 | English term}`，后接定义段、可选注和可选来源。

# 符号和缩略语

A —— 示例面积，单位为平方米（m^2^）。

Q —— 示例流量，单位为立方米每天（m^3^/d）。

# 生成要求

## 基础要素生成

生成器应根据 YAML front matter 生成封面标准编号、标准中文名称、英文译名、一致性程度标识、发布实施日期和发布单位。

正文首页应在标准中文名称之后、范围章之前生成重要提示。

## 标准章导语生成

规范性引用文件章未手写导语时，生成器应自动补齐规范性引用文件常用导语。

术语和定义章未手写导语时，生成器应自动补齐“下列术语和定义适用于本文件。”。

符号和缩略语章未手写导语时，生成器应使用 `symbols_lead` 的内容生成导语。

## 术语块生成

显式术语块应生成术语条编号，术语和英文对应词应加粗显示。

术语定义、注和来源应保持在同一术语条目之后，来源应使用标准文件来源字符样式。
